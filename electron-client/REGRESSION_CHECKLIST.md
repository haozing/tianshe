# Electron Client Regression Checklist

This checklist covers the active Chihu Electron runtime. The current scope is Douyin/DouDian commerce plus shared desktop capabilities. PDD legacy workbench behavior is out of active scope.

## Automated Checks

Run the full local check:

```powershell
npm run check
```

Run the smoke suite:

```powershell
npm run smoke
```

Targeted smoke checks:

```powershell
npm run smoke:cookie
npm run smoke:http
npm run smoke:db
npm run smoke:files
npm run smoke:logs
npm run smoke:ui-contract
npm run smoke:maintenance
```

Manual desktop UI evidence:

```powershell
npm run record:desktop-ui-manual-evidence
npm run check:desktop-ui-manual-evidence
npm run check:desktop-ui-manual-ready
```

## Covered Areas

- JavaScript syntax for main, preload, scripts, and smoke files.
- `window.client` preload contract and matching main-process IPC handlers.
- Chihu runtime app icon at `assets/icon-chihu.png`.
- Default remote-web entry and environment override entry.
- Cookie/session helpers, including temporary partition smoke coverage.
- HTTP proxy helpers, including GET, POST JSON, Base64 response handling, and `Set-Cookie` writeback.
- NeDB and SQLite helpers under temporary `userData`.
- File helpers, including save, download, cancel download, upload, and explorer error handling.
- Notification and log IPC contracts.
- Window helpers, hidden child window lifecycle, information reads, JavaScript execution, and destroy flow.
- Maintenance helpers, including invalid partition cleanup and client version data.
- Store/DouDian service bridge contract exposed through the Chihu store IPC layer.

## Manual Or External Checks

Keep these out of the default smoke suite because they can touch user data, open system UI, or depend on external services:

- Real `selectDirectory` system dialog.
- Real `openPathInExplorer` system explorer opening.
- Real system notification display and click behavior.
- Real auto-update download/install flow.
- Real logged-in DouDian platform requests against a user profile.

## Out Of Scope

- PDD workbench development.
- PDD plugin entry points or `/pdd/...` popup flows.
- PDD-specific process checks and enum flows.
- Historical DouDian sampling artifacts that are no longer wired to current package scripts.

## Generated Artifacts

`electron-client/artifacts/` is generated by smoke and manual evidence checks. It is ignored by git and can be deleted safely.
