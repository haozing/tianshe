## 1. 软件概述

**店汪汪商家助手**是一款面向**抖音电商（抖音小店）商家**的桌面端运营辅助工具，由广东凡滴科技有限公司开发。软件核心功能包括：

| 维度 | 说明 |
|------|------|
| 目标平台 | 抖音电商 (jinritemai.com) |
| 目标用户 | 抖音小店商家、无货源店群运营者 |
| 核心价值 | 多平台商品采集上架、自动化营销活动、多店铺批量管理 |
| 版本 | v2.5.1 |
| 运行环境 | Windows, 32-bit (x86) |
| 保护方案 | DNGuard HVM + Costura.Fody + Eazfuscator |
| 官网 | fandikj.com |

### 3.3 四大自动任务系统

这是软件的核心自动化功能，模拟商家在抖音后台的日常操作：

自动参与抖音平台营销活动：

- 满减活动创建
- 多件优惠活动创建

- 活动状态监控与自动续期

#### 3.3.2 优惠券任务 (CouponAutoTaskOpenerHelper)

自动创建和管理店铺优惠券：
- 查询现有优惠券列表
- 检查优惠券状态
- 自动创建新优惠券
- 店铺券管理

#### 3.3.3 联盟补贴任务 (UnionAllowanceAutoTaskOpenerHelper)

自动参与抖音联盟补贴计划：
- 创建联盟补贴申请
- 搜索可补贴商品
- 检查扣款创建条件
- 编辑/禁用补贴申请
- 补贴记录查询

#### 3.3.4 千川广告任务 (QianChuanAdAutoTaskOpenerHelper)

自动管理巨量千川广告投放：
- 广告计划创建
- 投放策略管理
- 预算自动调整
- 效果数据监控

### 3.4 登录系统

采用**双引擎**浏览器方案：

| 引擎 | 窗体类 | 用途 |
|------|--------|------|
| CefSharp | `form_login_Browser` | 主登录浏览器，Chromium内核 |
| WebView2 | `form_login_WebView2` | 备用登录，Edge内核 |

登录流程：
1. 内嵌浏览器打开抖音商家后台登录页
2. 用户手动扫码/输入账号密码
3. 程序捕获登录Cookie和Token
4. 使用 `DouShopLoginEncryptor` / `DYLoginParamEncrypt` 加密存储

### 3.5 卡密系统

软件采用**卡密授权**模式：

```
_kamiTimer (定时器)
  └── kamiTimer_Tick (定时检查授权状态)
        └── 授权过期 → buy_kami() (引导购买卡密)
```

- 定时检查授权有效期
- 授权到期后锁定功能
- 引导用户购买新卡密续期

## 5. API 请求参数格式

### 5.1 标准请求头

所有发往 `jinritemai.com` 的API请求都需要携带以下标准参数：

```
POST https://fxg.jinritemai.com/{api_path}

参数:
  appid=1                    # 应用ID（固定值1）
  _bid={business_id}         # 业务ID标识
  s={random_string}          # 随机数防重放
  verifyFp={device_fp}       # 设备指纹（VerifyCenter生成）
  fp={fingerprint}           # 备用指纹
  msToken={anti_bot_token}   # 反Bot Token（滑块验证后获取）
  a_bogus={signature}        # 反Bot签名（JS加密生成）
  _={timestamp}              # Unix时间戳（毫秒）
```

### 5.2 请求流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 构造请求  │───→│ 生成指纹  │───→│ 签名加密  │───→│ 发送请求  │
│ 参数拼装  │    │ verifyFp │    │ a_bogus  │    │ HTTP POST│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                       │               │
                       ▼               ▼
               ┌──────────┐    ┌──────────┐
               │ SIF反欺诈 │    │ JS签名   │
               │ 设备环境  │    │ 算法     │
               └──────────┘    └──────────┘
```

### 5.3 Cookie 认证

请求通过Cookie携带登录态：

```
Cookie: passport_csrf_token=xxx; sessionid=xxx; sessionid_ss=xxx; 
        sid_guard=xxx; uid_tt=xxx; uid_tt_ss=xxx; 
        sid_tt=xxx; ssid_ucp_v1=xxx; ...
```

## 6. 加密与安全机制

### 6.1 加密算法

| 算法 | 类名 | 用途 |
|------|------|------|
| AES-CBC | `AesCryptoServiceProvider` | 数据库加密、敏感数据加密 |
| RSA | `RSACryptoServiceProvider` | 密钥交换、请求签名 |
| MD5 | `MD5CryptoServiceProvider` | 数据完整性校验、签名 |

### 6.2 专用加密器

| 加密器 | 用途 |
|--------|------|
| `DouShopLoginEncryptor` | 登录凭证加密存储 |
| `DYLoginParamEncrypt` | 抖音登录参数加密（模拟前端加密逻辑） |

### 6.3 反Bot机制

软件模拟了抖音前端的反Bot安全体系：

| 组件 | 说明 |
|------|------|
| **SIF (Secure Identity Framework)** | 抖音设备指纹体系，采集浏览器/系统环境 |
| **VerifyCenter** | 滑块/点选验证码服务 |
| **msToken** | 基于Cookie的反Bot Token，需通过验证获取 |
| **a_bogus** | JS层签名算法，对请求参数进行HMAC签名 |
| **Slardar** | 字节跳动前端监控SDK |
| **OWL** | 错误录制与回放系统 |

### 6.4 密钥资产

程序中发现的密钥资产：

| 类型 | 数量 | 长度 | 格式 |
|------|------|------|------|

## 10. DNGuard HVM 保护分析

### 10.1 保护原理

```
编译时:
  IL代码 → DNGuard加密 → 加密元数据嵌入PE
  
运行时:
  CLR加载 → 加密元数据 → JIT请求方法 → DNGuard按需解密 → 正常JIT编译
```

| 阶段 | 行为 | 可逆性 |
|------|------|--------|
| 静态加密 | 所有方法IL被加密存储 | 文件级无法直接读取 |
| JIT触发 | 仅在方法被调用时解密 | 内存中可读取 |
| 运行时 | ClrMD可读已解密方法 | ✅ 可逆 |

### 10.2 分析方法与结果

| 方法 | 工具 | 结果 |
|------|------|------|
| 静态反编译 | dnSpy | ❌ 方法体为空/乱码 |
| ClrMD内存读取 | ClrMD (附加进程) | ✅ 成功读取1101个已解密方法 |
| dnSpy附加 | dnSpy (Attach) | ⚠️ 构造函数可见，批量导出因元数据膨胀失败 |
| CLR Profiler | ICorProfiler | ❌ 环境限制无法加载 |

### 10.3 ClrMD提取结果

通过附加到运行中的进程，使用ClrMD成功提取：

- **2,869** 个C#类型定义
- **1,101** 个已解密的应用方法（非框架方法）
- 类结构、字段名、方法签名完整可见
- 方法体IL在JIT后可部分读取
